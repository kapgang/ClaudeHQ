# Draft Status Email

## Instructions

Generate professional weekly status update emails for Engagement Teams:

1. Ask for the project name and ET contact
2. Ask what was completed this week
3. Ask what's currently in progress
4. Ask about any blockers or questions
5. Ask about next steps/planned work
6. Generate a well-formatted email using the template below

## Email Template

```
Subject: [Project Name] - Weekly Status Update ([Date Range])

Hi [ET Contact],

Here's this week's status update for [Project Name]:

✅ COMPLETED THIS WEEK
[List accomplishments with specific details]
- Completed Workflow 1 for W2 data standardization
- Addressed nuances in HR dataset (department mapping)
- Generated initial QC outputs for review

🔄 IN PROGRESS
[Current work being done]
- Building Workflow 3 for Time Tracking data
- Investigating discrepancy in employee counts

⚠️ BLOCKERS / QUESTIONS
[Items needing ET input or attention]
- Need clarification on how to handle contractors vs FTEs
- Waiting on updated GL file with Q4 data

📋 NEXT STEPS
[Planned work for next week]
- Complete WF3 and integrate with consolidated workflow
- Run full QA process on all outputs
- Prepare deliverables for client review

Please let me know if you have any questions or need additional details on any of these items.

Thanks,
[Your Name]
```

## Best Practices

- Be specific with accomplishments (mention workflow numbers, datasets, etc.)
- Frame blockers as questions to make them actionable
- Use bullet points for readability
- Keep tone professional but conversational
- Include enough detail that ET understands progress without asking follow-ups

## Tone Guidelines

- Professional but approachable
- Solution-oriented (suggest alternatives when blocked)
- Transparent about challenges
- Proactive about next steps

## Example Triggers

- "Draft my Thursday status email"
- "Create weekly update for [project]"
- "Generate status email"
- "Write ET update"

## Output

Provide the complete email text ready to copy/paste into Outlook or email client.
